Armagun? Inkgun!
Now you can use Squids as your new weapon for... inkfun I guess

## Items
### Inkgun
- Shoots ink that can:
	- Unglow signs
	- Blind players
- Command to get: ```/function give:squidgun/ink_gun```
### Glow Inkgun
- Shoots glow ink that can:
	- Glow signs
	- Glow entitiesa
	- Blind players
- Command to get: ```/function give:squidgun/glow_ink_gun```
### Flame Inkgun
- Shoots flame ink that can:
	- Cover all with fire
	- Damage entities
- Command to get: ```/function give:squidgun/flame_ink_gun```
### Flame Ink Sac
Just item with no functionality
- Command to get: ```/function give:squidgun/flame_ink_sac```
